**Auto-provisioned pinned build tools**

- `bun`/`pnpm`/`go` are downloaded into `.ghost-cache/toolbox` on demand, SHA-256 verified against the compiled-in table, non-blocking doctor/preflight
- PATH prefixing for host prefetch and sandbox build
- Sharded range fetch for large downloads; host prefetch precreates redirect dirs
- netlog endpoints: `release-assets.githubusercontent.com`, `dl.google.com`
